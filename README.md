# Paper Toss Rage

A paper toss game for exam season. Pick your degree (NUS or NIT Calicut), crumple a question from it, and throw it in the bin.

**Play:** https://jay-jay-tee.github.io/paper-toss-rage/

- 28 degrees (18 NUS, 10 NITC) with 12 questions each, plus a chaos mode that mixes them all
- Three wind settings: Breeze, High Wind and Weird Wind
- Combos, a bin that starts moving halfway through, and a grade at the end

## Files

- `index.html` is the game (also published as a Claude artifact)
- `docs/index.html` is the copy GitHub Pages serves. Run `python3 build.py` after editing the game to update it.
