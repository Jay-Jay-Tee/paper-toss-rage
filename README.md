# Paper Toss Rage

A cartoon paper-toss stress buster for exam season. Pick your degree (NUS or NIT Calicut), read a painfully niche exam question, tap to crumple it, and swipe to throw it into the bin.

**Play:** https://jay-jay-tee.github.io/paper-toss-rage/

- 28 degrees (18 NUS, 10 NITC), 12 questions each, plus Chaos Mode with every degree mixed
- Wind modes: Breeze, High Wind, and Weird Wind (swirls, updrafts, U-turns, and sometimes it lies)
- Combos, rim rattles, a bin that starts moving, and a marked script with your grade at the end

## Files

- `index.html` is the game source (also published as a Claude artifact).
- `docs/index.html` is the standalone page GitHub Pages serves. Rebuild it after editing the game with `python3 build.py`.
